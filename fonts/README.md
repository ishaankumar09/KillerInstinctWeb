# Satoshi Font Files

Place your Satoshi font files in this directory with the following names:

- `Satoshi-Regular.woff2` (weight: 400)
- `Satoshi-Medium.woff2` (weight: 500)
- `Satoshi-Bold.woff2` (weight: 700)

The font is configured in `app/layout.tsx` and will be applied globally across the entire website.

If you need additional weights or styles, you can add them to the `localFont` configuration in `app/layout.tsx`.
